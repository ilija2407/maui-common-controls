# BorderlessEntry.Maui

`BorderlessEntry` is a small .NET MAUI control that provides an `Entry` without the default platform border/underline styling.

## Intention

The goal is to make it easy to achieve a clean, borderless text input across platforms while still using the standard MAUI `Entry` behaviors (text, keyboard, validation, bindings, etc.).
